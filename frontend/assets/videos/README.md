# Weather Background Videos

Place short, looping MP4 video files here to enable the video background feature.

## Required filenames

| File          | Condition           |
|---------------|---------------------|
| `clear.mp4`   | Sunny / Clear sky   |
| `cloudy.mp4`  | Overcast / Clouds   |
| `rain.mp4`    | Rain / Drizzle      |
| `storm.mp4`   | Thunderstorm        |

## ✅ Without videos

The app works perfectly without these files.
CSS gradient fallbacks are always active — the app will show smooth
colour transitions based on weather conditions just like before.

## Where to download free videos

Search these sites for free CC0 / royalty-free looping weather videos:

- **Pixabay** — https://pixabay.com/videos/
  - Search: "rain loop", "sunny sky loop", "storm lightning loop"

- **Pexels** — https://www.pexels.com/videos/
  - Search: "rain background", "clear sky", "storm"

## Tips for good video backgrounds

- Keep files under **5 MB each** for fast loading
- Recommended resolution: **1280×720** (720p) is enough for a background
- Duration: **10–30 seconds** looping
- Download in **MP4** format (H.264 codec)
- Avoid videos with large moving subjects — subtle atmospheric loops work best
